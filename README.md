# Металлические навесы

Одностраничный сайт-портфолио мастера по изготовлению и монтажу металлических навесов.

## Публикация

Сайт автоматически собирается и публикуется в GitHub Pages при отправке изменений в ветку `main`.

Адрес проекта: <https://vissmu.github.io/zubr-navesy.github.io/>

В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в поле **Source**.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка готовой версии:

```bash
npm test
```
